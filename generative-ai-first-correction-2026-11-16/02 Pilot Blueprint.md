# AI-first pilot blueprint — BlackBerry case study
Target: 10 min, 8–12 min acceptable. Hybrid pilot: 180 usable generated-video seconds (30%); remaining visuals use original AI keyframes/stills, restrained parallax, maps/timelines, and charts. Human script, research, claim-check, edit, narration review and release sign-off. Narration below is purpose, not factual copy; source each claim before scripting.

|Time|Scene purpose / narration|Visual and generation method|Usable video target|
|---|---|---|---:|
|0:00–0:45|Set up strategic question|Abstract handset-to-touch interface, T2V|30s|
|0:45–2:15|Establish early product advantage|AI keyframe + I2V device-era atmosphere|35s|
|2:15–4:00|Explain platform/ecosystem shift|I2V sequence; original diagram anchors claims|40s|
|4:00–6:15|Examine company response|Generated boardroom metaphor + sourced timeline|30s|
|6:15–8:30|Show market consequence, nuance|I2V transition + custom ecosystem graphic|30s|
|8:30–10:00|Summarize lessons, avoid single-cause claim|AI image, subtle I2V close|15s|

**Attempts/cost:** For scene target t seconds and usable yield p, generated duration = t/p; attempts = ceil(t/(p×provider output seconds per attempt)). Pilot examples must test p=25/40/60%, not assert these as model performance. Per-scene vendor cost = generated seconds × quoted rate (or billed credits); A Runway Dev API rate snapshot is in 10 Vendor Pricing and Scenario Calculations; output-only cost can be calculated, but provider output limits, failure yield, commercial license and per-scene total attempts remain unverified. Compare T2V/I2V only after identical storyboard prompts/reference tests.

Generate keyframes first, lock palette/reference images, then animate shots where motion adds value. Human editor assembles and retimes; check artifacts, continuity, factual plausibility, rights and disclosure. Speech: select commercially licensed TTS, edit pronunciation and proof-listen. Obtain quotes for narration, images, music, storage and editing; add taxes/FX and any input-video surcharges before setting scene costs.
